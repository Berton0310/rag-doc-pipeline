# 人工驗證清單

verifier 為每個有 `@manual` 情境的任務產生 `T-xxx.md`，由使用者填寫結果。agent 不得代填。

## 格式

```markdown
# T-xxx 人工驗證

| # | 情境 | 要打開什麼 | 要看什麼 | 預期 | 結果（使用者填） | 備註 |
|---|---|---|---|---|---|---|
| 1 | <情境名稱> | outputs/xxx/document.md 第 4 頁 | 步驟 5 照片的描述 | 提到「關閉進膠閥」，沒有不存在的部件 | ☐ 通過 ☐ 不通過 | |
```

- 「要打開什麼」寫到檔案路徑與位置，讓使用者不用找。
- 「預期」用可以判斷是或否的句子。
- 有不通過的項目時，主 session 依 `dispatch` skill 的判讀規則處理。
