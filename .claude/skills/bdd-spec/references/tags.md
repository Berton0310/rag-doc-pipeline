# 標籤定義

## Feature 層級（必填，各選一個）

| 標籤 | 意義 |
|---|---|
| `@draft` | 討論中，不得派發 |
| `@approved` | 使用者已明確同意，可以派發 |
| `@module-<名稱>` | 所屬模組，名稱對應 `docs/ARCHITECTURE.md` |

## Scenario 層級（選填，可多個）

| 標籤 | 意義 | 自動檢查時 |
|---|---|---|
| `@manual` | 只有人能判斷，agent 不得判通過 | 排除，列入人工驗證清單 |
| `@gpu` | 需要 GPU 機器上的模型服務 | 排除，在 GPU 機器上另外跑 |
| `@network` | 需要連外部服務（例如 OpenRouter） | 排除，需要時另外跑 |
| `@slow` | 單一情境超過 30 秒 | 包含，但可以用參數略過 |

沒有標籤的情境就是一般自動情境，在筆電與 CI 上都必須能跑。
